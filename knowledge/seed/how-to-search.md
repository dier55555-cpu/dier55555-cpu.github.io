# Как искать дело на сайте суда

Модуль на всех сайтах одинаковый: `modules.php?name=sud_delo` («Судебное делопроизводство»).

Пользователю нужны хотя бы один из ориентиров:

1. Номер дела (например, 2-1234/2026).
2. ФИО участника.
3. Дата поступления или дата заседания.

Инструкция для ответа агента:

1. Определи район / суд.
2. Дай прямую ссылку на `sud_delo` этого суда.
3. Скажи: открыть «Поиск дел», выбрать первую инстанцию, ввести номер или фамилию.
4. Если карточка нашлась — там будут стороны, судья, движение, даты заседаний (если опубликованы).
5. Если не нашлось: проверить опечатку, другой район, мировой участок, арбитраж (это уже не эти сайты).

Агент **не парсит sudrf в момент чата**. Живой HTML с облачного сервера почти всегда режется фильтром безопасности ГАС «Правосудие». Актуальные карточки дел попадают в базу знаний только после выгрузки парсером с российского IP.
