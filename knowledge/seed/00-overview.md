# Районные суды г. Воронежа — справочник для ИИ-агента

Дата сборки справочника: 2026-08-19.
Официальный источник по делам, расписанию и точной подсудности улиц — сайты судов ГАС «Правосудие».
Телефоны и адреса ниже собраны из публичных справочников судов и **нужно сверять** с разделом «Контакты» на сайте суда, если пользователь собирается ехать или звонить.

## Как выбирать суд

1. Гражданские иски по общему правилу подаются в суд **по месту жительства ответчика** (или по адресу организации).
2. Если известен **район города** (Советский, Коминтерновский, Железнодорожный, Левобережный, Центральный, Ленинский) — это соответствующий районный суд.
3. Если известна только улица — сначала определить район Воронежа, затем суд. Точные списки улиц для мировых судей живут на сайте суда в разделе территориальной подсудности; не угадывать границы участков.
4. Мировые судьи рассматривают часть дел (приказы, небольшие суммы и др.). Если сумма/категория неясна — объяснить разницу и дать ссылку на поиск дел и на контакты районного суда.

## Что агент может ответить уверенно

- Какой из шести районных судов соответствует названному району Воронежа.
- Адрес здания, почта, основные телефоны, ссылка на официальный сайт и на модуль «Судебное делопроизводство».
- Как самому найти дело: номер дела / ФИО / дата на сайте суда.

## Что агент не должен выдумывать

- Статус конкретного дела, дату заседания, ФИО судьи по делу, текст решения — если этого нет в базе знаний после свежего парсинга.
- Точную подсудность конкретной улицы мировому участку без выгрузки с сайта суда.
