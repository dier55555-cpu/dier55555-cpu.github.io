# Правила рабочей области

## Структура проектов

Каждый проект — **отдельная папка**. Платформа определяет, где лежит папка.

| Платформа | Куда класть проект |
|-----------|-------------------|
| **Ноя (Noya / Noe)** | `noya/projects/<имя-проекта>/` |
| Любая другая | соседняя папка в корне: `<платформа-или-имя-проекта>/` |

Примеры:

```
/
├── AGENTS.md
├── noya/                          # всё, что связано с платформой Ноя
│   ├── _shared/                   # общие материалы (читать всегда для Нои)
│   │   ├── prompt-methodology.md
│   │   └── ...
│   └── projects/
│       ├── vrn-courts-kb/
│       └── another-noya-bot/
├── bitrix/                        # другой платформенный контур
│   └── court-monitor/
└── index.html                     # корневой сайт репозитория (не проект Нои)
```

## Обязательные правила для агента

1. **Не смешивать платформы.** Файлы Нои — только под `noya/`. Файлы других платформ — не внутрь `noya/`.
2. **Новый проект Нои** → создать `noya/projects/<slug>/` и работать только там (кроме чтения `_shared`).
3. **Новый проект не на Ное** → создать соседнюю папку в корне репозитория (или внутри уже существующей папки платформы).
4. **Перед реализацией на Ное** обязательно прочитать актуальные файлы из `noya/_shared/` (методология промптов и прочее) и применять их.
5. **Не класть код проекта в корень** репозитория и не размазывать один проект по нескольким несвязанным папкам.
6. Общие для всех проектов Нои документы, шаблоны и методологии класть в `noya/_shared/`, а не копировать в каждый проект.

## Имена папок

- Только латиница, строчные буквы, дефисы: `vrn-courts-kb`, `prompt-lab`.
- Имя проекта должно быть понятным без контекста чата.
