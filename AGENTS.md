# Правила рабочей области

## Структура проектов

Каждый проект — **отдельная папка**. Платформа определяет, где лежит папка.

| Контур | Куда класть |
|--------|-------------|
| **Ноя (Noya / Noe)** | `noya/projects/<имя-проекта>/` |
| **Всё остальное** | `другие/<имя-проекта>/` |

Зачем так: инструкции, методология промптов и прочие общие файлы Нои живут только в `noya/_shared/`. Их нужно применять **только** к проектам под `noya/`. Папка `другие/` специально отделена, чтобы эти правила Нои не смешивались с остальными проектами.

Примеры:

```
/
├── AGENTS.md
├── noya/                          # только платформа Ноя
│   ├── _shared/                   # инструкции Нои (не для «других»)
│   │   ├── prompt-methodology.md
│   │   └── ...
│   └── projects/
│       └── anna/                  # существующий проект Анны на Ное
├── другие/                        # всё вне Нои
│   └── юристы/                    # проект с юристами
└── index.html
```

## Обязательные правила для агента

1. **Не смешивать контуры.** Файлы Нои — только под `noya/`. Всё остальное — только под `другие/`.
2. **Проект Нои** → `noya/projects/<slug>/` (кроме чтения `_shared`).
3. **Проект не на Ное** → `другие/<slug>/`.
4. **Перед реализацией на Ное** обязательно прочитать `noya/_shared/` и применять.  
   **В `другие/` эти файлы не читать как обязательные инструкции и не навязывать стиль/методологию Нои.**
5. Не класть реализацию проектов в корень репозитория.
6. Общие для всех проектов Нои материалы — в `noya/_shared/`, без копипаста в каждый проект.

## Имена папок

- Папки контуров зафиксированы: `noya/`, `другие/`.
