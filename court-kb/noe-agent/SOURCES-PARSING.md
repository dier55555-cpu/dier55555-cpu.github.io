# Какие сайты мы можем парсить (для юриста / продукта)

Это не промпт агента, а наша карта источников. Анна в чате обещает только то, что реально подключено.

Кратко: **живой парсер карточки дела** — шаблон sudrf G1/U1, в n8n/API зашиты
**6 райсудов Воронежа**. **Справка с сайта** (режим, контакты, структура,
подсудность, реквизиты) — любой официальный сайт суда из БЗ через то же действие
«Дело» (`mode=info`, `website`+`topic`). Часы в БЗ не храним. Неофициальные
агрегаторы не используем.

Резидентный прокси к sudrf — это доступ к **открытым** страницам (262-ФЗ): датацентры и зарубежные IP sudrf режет WAF. Это не обход закрытых кабинетов и не «взлом». Закрытые данные, капчи «для своих» и обход блокировок личного кабинета не делаем. Один sticky-IP выгорает — используем **пул портов** того же аккаунта (и при необходимости второй провайдер), суды не молотим.

## Что парсер sudrf реально достаёт (когда сайт отвечает)

- Номер, стороны (как в таблице поиска / карточке).
- Движение дела, даты заседаний — если суд их вывел в HTML.
- Ссылку на карточку на сайте суда.

Не достаёт надёжно: полный архив PDF, ИНН/ОГРН как поле поиска (в форме G1/U1 этого нет), «все дела организации по России», кабинет/ВКС, если суд это не написал.

## Вспомогательные (СудАкт, «Картотека» и т.п.)

**Не парсим и не используем как источник.** В промпте Анны запрещены. Даже «только сверить» не подключаем: расхождение с официальным сайтом и риск устаревших копий.

## Функции из ТЗ, которые не про парсинг одного сайта

| Функция | Статус |
| --- | --- |
| Реестр дел юриста | Нет хранилища в Ное под это |
| Напоминание за 24–48 ч до слушания | Нет cron/уведомлений у Анны |
| Мониторинг смены статуса | Нет периодического опроса |
| Сводка по всем делам клиента | Нет; вручную — одно дело за раз |
| Поиск по ИНН/ОГРН | Нет в форме sudrf G1/U1; в kad — когда появится парсер арбитража |

Следующий разумный шаг продукта (когда прокси к sudrf снова стабилен): не новые порталы, а **тот же G1/U1 на любой sudrf-домен из таблицы**, вместо шести slug’ов Воронежа.
