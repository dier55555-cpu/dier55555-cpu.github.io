# Google Calendar для Анны

Интеграция в кабинете создана: тип `google_calendar`, имя «Google Calendar»
(`f3fd3315-8a62-4e6d-8ffa-b57cfe5dcf60`), привязана к агенту Анна.
Пока **не включена**: нужен `calendar_id`.

## Что сделать Александру

1. В Google Calendar создать (или выбрать) календарь для заседаний.
2. Открыть доступ на редактирование сервисному аккаунту Нои:
   `noya-calendar@noya-calendar.iam.gserviceaccount.com`
3. Скопировать ID календаря (часто это email вида `...@group.calendar.google.com`
   или `primary` для основного).
4. Написать ID сюда / в кабинете Нои → Интеграции → Google Calendar → адрес календаря.
5. После заполнения включить интеграцию (verify).

Пока календарь выключен, Анна по промпту предлагает follow-up в чате и не врёт,
что событие уже в Google.
