# Действие Дело — описание для AI (кабинет)

Когда вызывать: клиент назвал суд (один из доступных slug) и номер дела или фамилию участника. Без суда и без номера/фамилии не вызывай.

Один общий Body (поля собирай из диалога):

{
  "court_slug": "<slug суда>",
  "case_number": "<номер дела или пустая строка>",
  "last_name": "<фамилия или пустая строка>"
}

Правила сборки:
- court_slug обязателен. Допустимые: sovetsky-vrn (Советский), kominternovsky-vrn (Коминтерновский), zheleznodorozhny-vrn (Железнодорожный), levoberezhny-vrn (Левобережный), centralny-vrn (Центральный), lensud-vrn (Ленинский) — все г. Воронеж
- Нужен case_number ИЛИ last_name (хотя бы одно). Оба сразу можно
- case_number как на сайте, пример 2-123/2025. Нет номера → ""
- last_name — только фамилия участника. Нет фамилии → ""
- Не подставляй чужой slug. Суд не из списка выше → действие не вызывай, дай САЙТ из БЗ

Примеры Body:
1) По номеру: {"court_slug":"sovetsky-vrn","case_number":"2-123/2025","last_name":""}
2) По фамилии клиента: {"court_slug":"kominternovsky-vrn","case_number":"","last_name":"Иванов"}
3) Номер и фамилия: {"court_slug":"levoberezhny-vrn","case_number":"2-4936/2026","last_name":"Петров"}

Ответ клиенту только из результата. status error/not_found → не выдумывай карточку, дай сайт суда.
