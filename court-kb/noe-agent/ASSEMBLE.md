# Сборка в кабинете НОЕ (клики)

Кабинет: **Студия ДендрИИт**. Доску «Основной» и агента «Легион — продавец (тест)» не открывать и не править.

Канал на этом этапе: **тестовый чат агента в НОЕ**. Виджет / Telegram / сайт не подключать.

## Шаг 1. Новая доска

Создать доску с названием **Ассистент-юриста**.  
Это вторая доска в том же кабинете, не другой кабинет.

## Шаг 2. Новый агент

На этой доске создать агента:

- имя: **Ассистент-юриста**
- тип: справочный / квалификационный, не продавец
- дожим: выкл
- канал: тестовый

Если платформа ответит, что агентов больше нельзя создать (`агентов_доступно: 1`) — остановиться и зафиксировать ответ тарифа. Легиона не удалять.

## Шаг 3. Инструкция

Вставить целиком текст из `prompt.md`. Сохранить.

## Шаг 4. База знаний

Загрузить четыре файла из `kb/` как документы БЗ этого агента (не Легиона):

1. `01-sudy-voronezha.md`
2. `02-chto-umeyu.md`
3. `03-kak-nayti-delo.md`
4. `04-ogranicheniya.md`

URL сайтов судов в БЗ **не** добавлять автоимпортом: без проверки IP сервер НОЕ может сохранить страницу-заглушку блокировки вместо сайта.

## Шаг 5. Действия — пока пусто

На первом тесте HTTP-действие не вешать. Агент должен пройти диалоги 1–6 и 8 из `test-dialogs.md` только на инструкции и БЗ.

## Шаг 6. Тестовый прогон

Открыть тестовый чат агента и пройти `test-dialogs.md`.  
Сломанный ответ = править `prompt.md` / БЗ, не парсер.

## Шаг 7. Потом (не сейчас)

Когда решите, что тестовый канал ок:

1. На сервере НОЕ поднять `court-kb` (`docker compose`) и проверить, открываются ли сайты судов.
2. Импортировать в n8n `n8n/court-agent-webhook.json`, включить Active.
3. Добавить агенту HTTP-действие по `actions.md`.
4. Прогнать диалог 7 (поиск дела).
5. Тогда же решить канал: виджет / Telegram / сайт.
