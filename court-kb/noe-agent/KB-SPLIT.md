# Разбиение справочника судов для БЗ Нои

Тариф: **20 документов** на кабинет. Легион занимает 6 → юристу остаётся ≤14.
Схема: **Суды-1…5** + **Мировые-1…7** = **12** документов юриста (FAQ Воронежа из БЗ убраны: часы/телефон — с сайта при парсинге).

Правило нарезки: **один субъект РФ целиком в одной части**, без разрезания региона.

## Было в старой БЗ «Суды России» (зачем каждый файл)

| Файл | Зачем был |
| --- | --- |
| `Суды России` (таблица, ~2251 строка) | Справочник районных/городских/областных/апелляции/кассации/ВС |
| `01-kak-nayti-sud.md` | Как искать суд по городу/району |
| `02-chto-umeyu.md` | Что умеет агент |
| `03-kak-nayti-delo.md` | Как искать дело |
| `04-ogranicheniya.md` | Не юрконсультация, ПДн |
| `*-vrn-faq.md` (6 шт.) | Часы/телефон/адрес шести райсудов Воронежа |

Короткие `01…03` внесены в промпт (как искать суд и дело). `04` — в правилах промпта. FAQ Воронежа из БЗ удалены.

## Мировые-1…7

~1100–1110 участков в каждой, регион целиком; нарезка по размеру (Москва одна, МО в другой и т.д.). Списки — `manifest.json`.

## Имена по методологии Нои

Короткие имена БЗ и действие **Дело** (бывш. «Поиск дела в суде») — меньше символов в промпте и в вызовах.
