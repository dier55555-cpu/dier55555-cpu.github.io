## Статус на 20.08.2026 — слой 1 (справочник) в проде на реальных данных

- **Блокировка sudrf.ru обойдена.** Российский хостинг сам по себе не помогает (проверено на sweb.ru — тоже блокируют). Помог **резидентный прокси** (`pool.proxy.market`, гео Россия, sticky-сессия) — с ним сайты судов открываются нормально. Ключевая находка: помимо гео, WAF требует полноценные браузерные заголовки (Accept, Accept-Language, Accept-Encoding и т.п.) — без них отдаёт "(B) Данный запрос некорректен" даже с российского IP. Обе находки внесены в `scraper/fetch.py`.
- **Все 6 судов реально собраны** через `scraper.crawl` с сервера sweb.ru (`~/court-kb-app` на `gruzvmig.ru`, отдельно от сайта клиента `studiodendriit_ru`) — по 14-15 страниц с каждого суда, включая расписание заседаний (`modules.php?name=sud_delo`).
- Из собранных данных извлечены точные адрес/телефон/e-mail/часы работы каждого суда и загружены в БЗ юриста в формате «вопрос-ответ» (`*-faq.md`, 6 документов) — так модель находит нужный факт с высоким сходством (0.6–0.75) по прямому вопросу пользователя.
- Лимит тарифа Нои — 20 документов на аккаунт (общий с Легионом, у него занято 6). Подробные "сырые" документы по судам удалены, оставлены только компактные FAQ + 4 общих документа = 10 у юриста.
- **Важно:** после массовых правок БЗ первый тестовый вызов может закешироваться на предыдущем состоянии контекста — если ответ выглядит "устаревшим", повторите запрос с новым `test_session_id`.
- Сквозные тесты подтверждены: часы/адрес/телефон по разным судам отвечают точно с их реального сайта, вопрос не по теме (например, про товары Легиона) — вежливый отказ без путаницы агентов.
- n8n-процесс «Суды Воронежа — вебхук юриста» и инструмент «Поиск дела в суде» (слой 2) пока на заглушке `disabled` — сам поиск конкретного дела по номеру/фамилии ещё предстоит подключить к прокси таким же образом.
- На доске есть пустой инструмент «Новое действие» (создан вручную ранее, URL пустой) — решите сами: удалить или донастроить.
