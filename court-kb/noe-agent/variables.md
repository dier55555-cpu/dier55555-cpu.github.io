# Переменные агента Анна

Создаются в Ное: `POST /api/agents/:id/variables`, `ai_detect: true`.

| Переменная | Зачем |
| --- | --- |
| Имя клиента | Как представился |
| Телефон клиента | Контакт для напоминаний |
| Регион суда | Субъект РФ |
| Город суда | Город |
| Район суда | Район города |
| Название суда | Из БЗ |
| Сайт суда | САЙТ из БЗ → в Body действия 'Дело' |
| Номер дела | Поиск карточки |
| Фамилия участника | Поиск карточки |
| Дата слушания | Календарь / follow-up |
| Время слушания | Календарь / follow-up |
| Зал суда | Текст события |
| Тема запроса | hours / contacts / case / calendar … |

В промпте: блок «ПЕРЕМЕННЫЕ» — заполнять по ходу, не переспрашивать.
