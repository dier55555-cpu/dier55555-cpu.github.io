# Действия агента (подключать после вебхука n8n)

На первом тесте в канале НОЕ агент должен работать **без действий** — только инструкция + БЗ.

Когда на сервере НОЕ поднят `court-kb-api` и в n8n включён воркфлоу `court-agent-webhook.json`, добавьте одно HTTP-действие.

## Действие: Запрос к судам

- Тип: HTTP Request
- Метод: POST
- URL: Production URL вебхука n8n, вида `https://<домен-НОЕ>/webhook/court-agent`
- Заголовок: `Content-Type: application/json`
- Таймаут: не меньше 90 секунд (поиск дела может идти через капчу)

### Тело — список судов

```json
{ "action": "list_courts" }
```

Когда вызывать: пользователь не знает, какой суд выбрать, или спрашивает «какие суды ты знаешь».

### Тело — справка из базы

```json
{
  "action": "kb_search",
  "query": "{вопрос пользователя}",
  "court_slug": "sovetsky-vrn"
}
```

`court_slug` указывай, если суд уже известен. Допустимые slug:

| slug | Суд |
| --- | --- |
| sovetsky-vrn | Советский |
| kominternovsky-vrn | Коминтерновский |
| zheleznodorozhny-vrn | Железнодорожный |
| levoberezhny-vrn | Левобережный |
| centralny-vrn | Центральный |
| lensud-vrn | Ленинский |

Когда вызывать: адрес, часы, реквизиты, участки, как подать документы.

### Тело — карточка дела

```json
{
  "action": "case_lookup",
  "court_slug": "sovetsky-vrn",
  "case_number": "2-123/2026",
  "last_name": null,
  "production_type": "civil_first_instance"
}
```

Вместо номера можно передать `"last_name": "Иванов"`. Нужен хотя бы один из двух.  
`production_type` по умолчанию `civil_first_instance`; для уголовного — `criminal_first_instance`.

Когда вызывать: пользователь явно спросил статус / дату заседания / движение **конкретного** дела.

Когда **не** вызывать: общие вопросы, «какие дела бывают», перебор фамилий, «найди всё на Иванова по всем судам».

## Как отвечать по статусу результата

- `status: found` — перескажи карточку дела своими словами (движение дела, ближайшее заседание, стороны), не придумывай ничего сверх полученного текста.
- `status: not_found` — скажи, что по этим данным дело не нашлось, предложи проверить номер/фамилию или зайти в раздел «Судебное делопроизводство» на сайте суда.
- `status: error` — скажи, что не получилось выполнить поиск прямо сейчас (сайт суда мог быть временно недоступен), предложи попробовать ещё раз или зайти на сайт суда напрямую. Не выдумывай карточку.
- `status: disabled` — (устаревший статус для судов без `case_search.enabled`, сейчас не должен возвращаться) — так же честно говорит, что поиск недоступен.
