# Правила рабочей области

Локальный корень всего: **`/Users/user/Projects`**.  
В этом репозитории то же дерево зеркалится под **`Cursor/`**.

## Иерархия (не путать)

```
/Users/user/Projects/          (= Cursor/ здесь)
├── _shared/                   методология Нои
├── dendriit/                  КАБИНЕТ
│   ├── anna/                  ПРОЕКТ
│   └── bitrix-yurist/         ПРОЕКТ
└── <cabinet>/                 другой КАБИНЕТ
    └── <project>/             ПРОЕКТЫ внутри
```

- **Кабинет** = профиль Нои = один ключ `NOYA_KEY_<CABINET>`.
- **Проект** = папка внутри кабинета. В одном кабинете проектов несколько.
- Анна и Битрикс-Юрист — оба проекты кабинета **ДендрИИт**, не разные кабинеты.

## Обязательные правила для агента

1. Не плодить папки вне `/Users/user/Projects` (в репо — вне `Cursor/`).
2. Новый кабинет Нои → новая папка рядом с `dendriit/`, не внутри `anna/`.
3. Новый проект уже известного кабинета → папка **внутри** этого кабинета.
4. Перед работой на Ное: `_shared/` + `whoami` ↔ `<cabinet>/.cursor/rules/noya-cabinets.mdc`.
5. Ключи только в Cursor Secrets; в git — `${env:NOYA_KEY_…}`.
6. Ною не класть в `~/.cursor/mcp.json`.
7. Подробно: `Cursor/_shared/cabinets-and-keys.md`.
