# Правила рабочей области

Все проекты агента живут **только** внутри одной папки `Cursor/`. В корне репозитория/домашней папки лишних проектных папок не создавать.

## Структура

```
Cursor/
├── AGENTS.md
├── noya/                          # только платформа Ноя
│   ├── _shared/                   # инструкции Нои + cabinets-and-keys.md
│   │   ├── Методология_НОЯ.txt
│   │   ├── cabinets-and-keys.md   # несколько кабинетов / глобальные ключи
│   │   └── …
│   └── projects/
│       ├── _template/             # шаблон нового кабинета
│       ├── anna/                  # ДендрИИт / Анна
│       └── <slug>/                # другой кабинет Нои
└── другие/                        # всё вне Нои
    └── юристы/
```

| Контур | Куда класть |
|--------|-------------|
| **Ноя** | `Cursor/noya/projects/<имя>/` |
| **Всё остальное** | `Cursor/другие/<имя>/` |

Зачем раздельно: методология и инструкции Нои — только в `Cursor/noya/_shared/`. Их применяют **только** к проектам под `Cursor/noya/`. Папка `Cursor/другие/` отделена, чтобы правила Нои не смешивались с остальными проектами.

## Несколько кабинетов Нои

- Один кабинет Нои = одна папка `projects/<slug>/` = один секрет `NOYA_KEY_<SLUG>`.
- Ключи — в Cursor Secrets, не в git и не в `~/.cursor/mcp.json`.
- Перед правкой агента: `whoami` ↔ `.cursor/rules/noya-cabinets.mdc` этой папки.
- Подробно: `Cursor/noya/_shared/cabinets-and-keys.md`.

## Обязательные правила для агента

1. **Одна корневая папка:** все новые проекты — только под `Cursor/`. Не плодить папки рядом с `Cursor/` в корне.
2. **Не смешивать контуры.** Ноя → `Cursor/noya/`. Остальное → `Cursor/другие/`.
3. **Перед работой на Ное** читать `Cursor/noya/_shared/` и применять.  
   **В `Cursor/другие/` эти файлы не применять.**
4. Не класть реализацию проектов в корень репозитория (рядом с `index.html`).
5. Общие материалы Нои — в `Cursor/noya/_shared/`, без копипаста в каждый проект.
6. **Ключи Нои** не писать в файлы репозитория. Только `${env:NOYA_KEY_…}` в `mcp.json.example` / локальном mcp.json.
