# Проекты на Ное

Каждый **кабинет (профиль)** Нои = отдельная папка.

| Папка | Кабинет | Секрет Cursor |
|-------|---------|---------------|
| `anna/` | Студия ДендрИИт | `NOYA_KEY_DENDRIIT` |
| `_template/` | шаблон нового | `NOYA_KEY_<SLUG>` |

Новый кабинет: скопировать `_template/` → `<slug>/`, заполнить id и секрет по [`../_shared/cabinets-and-keys.md`](../_shared/cabinets-and-keys.md).
