# Ноя (Noya)

Всё, что делается **на платформе Ноя**, живёт здесь: `Cursor/noya/`.

## Папки

| Путь | Назначение |
|------|------------|
| `_shared/` | Инструкции Нои, методология, **кабинеты и ключи**. Не для `Cursor/другие/` |
| `projects/anna/` | Кабинет «Студия ДендрИИт» (Анна) |
| `projects/_template/` | Шаблон нового кабинета |
| `projects/<slug>/` | Другой кабинет / профиль Нои |

## Как добавить ещё один профиль

1. Выпустить **свой** ключ в кабинете Нои.
2. Положить его в Cursor Secrets как `NOYA_KEY_<SLUG>` (Runtime Secret).
3. Скопировать `projects/_template/` → `projects/<slug>/`, заполнить README и `noya-cabinets.mdc`.
4. В `mcp.json` подставить `${env:NOYA_KEY_<SLUG>}` (без литерала ключа).
5. Открыть папку проекта → `whoami` → сверить кабинет.

Подробно: [`_shared/cabinets-and-keys.md`](./_shared/cabinets-and-keys.md).

## Как добавлять артефакты проекта

1. Работать только внутри `Cursor/noya/projects/<slug>/`.
2. Перед реализацией читать `_shared/`.
3. Кросс-кабинетные знания — в `_shared/`, не копипастой в каждый проект.
