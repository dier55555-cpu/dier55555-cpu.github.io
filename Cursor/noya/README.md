# Ноя (Noya)

Всё, что делается **на платформе Ноя**, живёт здесь: `Cursor/noya/`.

## Папки

| Путь | Назначение |
|------|------------|
| `_shared/` | Инструкции Нои (методология промптов и т.д.). **Не для `Cursor/другие/`** |
| `projects/anna/` | Проект Анны |
| `projects/<имя>/` | Другие проекты на Ное |

## Как добавлять проект

1. Создать `Cursor/noya/projects/<slug>/`.
2. Прочитать `_shared/` перед реализацией.
3. Артефакты — только внутри папки проекта.
4. Кросс-проектные знания Нои — в `_shared/`.
