# Общие материалы платформы Ноя

Файлы относятся ко **всем** проектам в `Cursor/noya/projects/`.

Агент при любой задаче на Ное сначала просматривает `_shared/` и опирается на него.

## Что сюда класть

- методология написания промптов
- шаблоны промптов
- соглашения по knowledge base
- чеклисты выкладки на Ною

## Что сюда не класть

- код конкретного проекта → `Cursor/noya/projects/<имя>/`
- материалы вне Нои → только `Cursor/другие/<проект>/` (инструкции из этой папки туда не тащить)
