# Общие материалы платформы Ноя

Файлы относятся ко **всем** проектам в `Cursor/noya/projects/`.

Агент при любой задаче на Ное сначала просматривает `_shared/` и опирается на него.

## Что сюда класть

- методология написания промптов и работы на платформе
- инструкция промпт-инженера
- **схема кабинетов и глобальных ключей** (`cabinets-and-keys.md`)
- шаблоны промптов
- соглашения по knowledge base
- чеклисты выкладки на Ною

## Что сюда не класть

- код / промпты конкретного кабинета → `Cursor/noya/projects/<slug>/`
- API-ключи и токены → только Cursor Secrets
- материалы вне Нои → `Cursor/другие/<проект>/`

Читать: [cabinets-and-keys.md](./cabinets-and-keys.md).
