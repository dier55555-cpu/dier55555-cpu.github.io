# Методология написания промптов (Ноя)

> Рабочий документ. Дополняйте по мере практики — все проекты Нои опираются на актуальную версию.

## Цель

Единый стиль промптов для агентов/ботов на платформе Ноя: предсказуемое поведение, меньше галлюцинаций, удобная поддержка.

## Базовые принципы

1. **Одна роль — один промпт.** Чётко задайте роль, границы и что делать нельзя.
2. **Контекст отдельно от инструкции.** Инструкции не смешивать с фактами knowledge base.
3. **Явный формат ответа.** Если нужен список, JSON, шаги — опишите формат.
4. **Источники важнее догадок.** Нет данных в KB — сказать об этом, не выдумывать.
5. **Короткие правила сильнее длинных эссе.** Приоритеты и запреты — списком.

## Минимальный каркас системного промпта

```text
Роль: …
Цель: …
Границы: что можно / нельзя
Источники: откуда брать факты (KB, инструменты)
Формат ответа: …
Если не знаешь: …
```

## Чеклист перед выкладкой

- [ ] Роль и аудитория указаны
- [ ] Запреты и эскалации описаны
- [ ] Ссылки на KB / инструменты согласованы со структурой проекта
- [ ] Нет противоречий с файлами в `Cursor/noya/_shared/`
- [ ] Промпт лежит в `Cursor/noya/projects/<имя>/`, а не в корне и не в `Cursor/другие/`
- [ ] Кабинет подтверждён через `whoami` (см. `cabinets-and-keys.md`)
