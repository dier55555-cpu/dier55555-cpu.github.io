# Установка Aleksandr Beige на твоём Mac

Скопировать `.vsix` в «Настройки Cursor» **мало** — Cursor сам темы оттуда не подхватывает. Нужно поставить расширение.

## Вариант A — одна команда в Terminal

1. Положи `aleksandr-cursor-themes-1.1.0.vsix` куда угодно (Downloads / папка настроек Cursor).
2. В **Terminal** на Mac:

```bash
curl -fsSL -o /tmp/install-aleksandr-theme.sh \
  "https://raw.githubusercontent.com/dier55555-cpu/dier55555-cpu.github.io/cursor/aleksandr-themes-6562/Cursor/themes/aleksandr-cursor-themes/install-on-mac.sh"
bash /tmp/install-aleksandr-theme.sh
```

Скрипт сам найдёт `.vsix`, положит его в `~/.cursor/extensions/` и пропишет в настройках:

```json
"workbench.colorTheme": "Aleksandr Beige"
```

3. В Cursor: `Cmd+Shift+P` → **Developer: Reload Window**

## Вариант B — руками через Cursor

1. `Cmd+Shift+P` → **Extensions: Install from VSIX…**
2. Выбери файл `.vsix` (в Downloads или где скопировал)
3. **Reload Window**
4. **Preferences: Color Theme** → **Aleksandr Beige**

## Скачать VSIX, если файла нет

https://github.com/dier55555-cpu/dier55555-cpu.github.io/raw/cursor/aleksandr-themes-6562/Cursor/themes/aleksandr-cursor-themes/aleksandr-cursor-themes-1.1.0.vsix

Облачный агент **не может** поставить тему в Cursor на твоём Mac — только ты локально (команда выше или Install from VSIX).
