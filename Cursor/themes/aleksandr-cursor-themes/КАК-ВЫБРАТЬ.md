# Как поставить Aleksandr Beige (без поиска по диску)

Файла `/Users/user/Projects/themes/...` **нет** — темы лежат в этом git-репозитории на ветке PR, не в твоём `Projects`.

## Самый простой способ — скачать VSIX

1. Скачай файл по ссылке (Save As):

https://github.com/dier55555-cpu/dier55555-cpu.github.io/raw/cursor/aleksandr-themes-6562/Cursor/themes/aleksandr-cursor-themes/aleksandr-cursor-themes-1.1.0.vsix

2. В Cursor: `Cmd+Shift+P` → **Open IDE** (если нужно)
3. `Cmd+Shift+P` → **Extensions: Install from VSIX…**
4. Выбери скачанный `aleksandr-cursor-themes-1.1.0.vsix` (обычно в `~/Downloads`)
5. `Cmd+Shift+P` → **Developer: Reload Window**
6. `Cmd+Shift+P` → **Preferences: Color Theme** → **Aleksandr Beige**

## Если клонировал этот репозиторий

Путь относительно клона `dier55555-cpu.github.io` (нужна ветка `cursor/aleksandr-themes-6562`):

```text
Cursor/themes/aleksandr-cursor-themes/aleksandr-cursor-themes-1.1.0.vsix
```

На `main` этого файла пока нет — только в PR #11.

```bash
cd /путь/к/dier55555-cpu.github.io
git fetch origin cursor/aleksandr-themes-6562
git checkout cursor/aleksandr-themes-6562
```

Потом **Install from VSIX** на файл выше.
