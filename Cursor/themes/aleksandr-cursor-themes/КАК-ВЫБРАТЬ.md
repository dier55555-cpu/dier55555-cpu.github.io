# Как выбрать темы в обычном списке Cursor

Темы **не** появляются в `Preferences: Color Theme`, пока расширение не установлено один раз.

## Быстро (рекомендую)

1. Открой **IDE** Cursor (не Agents Window).
2. `Cmd+Shift+P` → **Extensions: Install from VSIX…**
3. Выбери файл:

```text
/Users/user/Projects/themes/aleksandr-cursor-themes/aleksandr-cursor-themes-1.0.0.vsix
```

4. `Cmd+Shift+P` → **Developer: Reload Window**
5. `Cmd+Shift+P` → **Preferences: Color Theme**
6. В списке будут:
   - Aleksandr Dark
   - Aleksandr Light
   - Aleksandr Night Gold

## Закрепить в настройках программы

`Cmd+Shift+P` → **Preferences: Open User Settings (JSON)** и добавь:

```json
"workbench.colorTheme": "Aleksandr Night Gold",
"workbench.preferredDarkColorTheme": "Aleksandr Night Gold",
"workbench.preferredLightColorTheme": "Aleksandr Light"
```

После этого тема подтянется при запуске, а переключение — как обычно через список тем.
