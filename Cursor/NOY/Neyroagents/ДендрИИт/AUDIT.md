### Почему не стартует, если клиент ничего не писал

Платформа **отменяет** запуск цепочки, если в диалоге нет сообщения клиента. В системных логах Авито дословно:

- `Дожим: выполнено частично (пропущено: клиент ещё ничего не писал)`
- `Дожим: пропущено — клиент ещё ничего не писал`

Бот пишет первым по объявлению → клиент молчит → через 61 мин триггер срабатывает → «Запустить цепочку» скип. Так десятки чатов без `role: user`.

Если клиент хоть раз написал: `Дожим: выполнено` + `✓ Запустить цепочку`.

Повтор на том же чате: `этот диалог уже проходил дожим — повторно не запускаем` (флаг `re_arm_on_silence` это не обходит).

Дожим = догнать того, кто уже писал. Холодное молчание после первого письма бота этой цепочкой не закрывается.

## Оценка работы

**Сильное:** один агент на Авито+сайт+VK+IG+почте; контекст объявления Авито включён; БЗ Архив; дожим 7 шагов с запретом повторов; follow-up на «руководство»; переменные под компанию/ФИО/email уже заведены; почтовый канал живой; действие исходящего письма **уже висит на этом агенте** и целится в `clientEmail` + `info@`.

**Дыры:**

1. «НАПИСАТЬ первым» не описано в промте и у tool пустой description — модель почти наверняка **не вызовет** его стабильно.
2. Нет сценария: клиент дал email руководства → записать в `clientEmail` (или отдельную переменную) → вызвать действие → коротко сказать, что письмо уйдёт с почты студии.
3. `clientEmail` = и клиент, и руководитель. Для схемы «письмо руководителю» лучше отдельная переменная, иначе путаница.
4. ОПЕРАТОР не ставит паузу: бот может продолжать писать после «передан Александру».
5. В промте Google Calendar, в tools его нет.
6. «Новое действие» — заглушка. Пустой «Новый агент» к каналам не привязан.
7. Исходящих кампаний нет — холодные списки пока только через это действие по одному адресу или через API кампаний.
8. Старые агенты АВИТО/Инста/4 сценария рядом на той же доске — риск править не того
9. Дожим не стартует без сообщения клиента (системный скип). Первый шаг цепочки ещё +3 суток. Повторно на тот же диалог не перезапускается

## Письма: как это стыкуется с замыслом

Замысел: из диалога (Авито) взять email и чем живёт компания → письмо с `info@`.

**Можно без второго агента**, если дописать промт и мини-промт действия:

1. Квалификация / объявление Авито → чем занимается компания.
2. Email в `clientEmail` (для руководителя — явно спросить и записать ФИО в `companyClientManagerFullName`).
3. `(Email записан и нужно письмо)`, вызови действие `'НАПИСАТЬ первым'`.
4. В `ai_instruction` действия: письмо руководителю, кейс из [Архив], как обращаться по ФИО, не шаблон «приветственное».

Второй агент нужен, если хотите **другой** тон на входящих ответах на `info@` (сейчас отвечает тот же продавец). Тогда почтовый канал перевешивают на письменника, а исходящее либо оставляют ему, либо оставляют `outreach_to_channel` на основном с `email_var`.

Передача диалога письменику Авито-чат в письмо не превратит. Кампании — для списков компаний, не для единичного адреса из чата.
