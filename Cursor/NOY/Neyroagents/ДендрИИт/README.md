# Проект: ДендрИИт

Кабинет: **Neyroagents** (`../`). Контур: `NOY/`.

Это не кабинет `NOY/dendriit/` (Анна / Легион). Здесь разбираем клиентский воркфлоу агентства.

| Поле | Значение |
|------|----------|
| Кабинет Нои | Neyroagents |
| Секрет | `NOYA_KEY_NEYROAGENTS` (`nk_live_…`) |
| Воркфлоу | **Студия ДендрИИт - АГЕНТ** (`X-Workflow-Id` — после `GET /api/workflows`) |
| Артефакты | только эта папка |

Перед правкой на платформе: открыть `Neyroagents/` → `whoami` / `GET /api/key/info` → сверить `account_name` с Neyroagents → заголовок `X-Workflow-Id` на этот воркфлоу (без него API молча отдаёт основное пространство).

Живой разбор доски: [AUDIT.md](./AUDIT.md). Методология: `Cursor/NOY/_shared/`.
