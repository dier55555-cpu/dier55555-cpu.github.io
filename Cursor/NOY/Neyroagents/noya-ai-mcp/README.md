# MCP кабинета Neyroagents

Подключение Cursor к кабинету **Neyroagents**. Не использовать ключ и пакет кабинета `NOY/dendriit/`.

| | |
|--|--|
| Секрет | `NOYA_KEY_NEYROAGENTS` / `.env` — не в git |
| API | `https://noya-ai.ru` |
| Пакет MCP | `GET https://noya-ai.ru/api/mcp-info` → `package_url` |
| Пример конфига | `../.cursor/mcp.json.example` |

Первая команда после подключения: `whoami`. Дальше проекты в соседних папках (`ДендрИИт/` и др.).
