# Кабинеты Нои, проекты и ключи

## Корень на Mac и в облаке

Локально:

```text
/Users/user/Projects/
```

В этом git-репо то же дерево зеркалится под `Cursor/` (= Projects).

```text
/Users/user/Projects/                 Cursor/  (в репо)
├── NOY/                              NOY/
│   ├── _shared/                      _shared/
│   ├── dendriit/                     dendriit/          ← кабинет
│   │   ├── noya-ai-mcp/              noya-ai-mcp/       ← MCP-подключение ДендрИИт
│   │   ├── anna/                     anna/              ← проект
│   │   └── легион/                   легион/            ← проект
│   └── Neyroagents/                  Neyroagents/       ← кабинет Нейроагентс
│       └── ДендрИИт/                 ДендрИИт/          ← агент «Студия ДендрИИт - АГЕНТ»
└── Другие/                           Другие/
    ├── bitrix-yurist/                bitrix-yurist/     ← НЕ Ноя (сервер отдельно)
    └── Саприн и партнеры/            Саприн и партнеры/ ← НЕ Ноя
```

## Не путать уровни

| Уровень | Что | Пример |
|---------|-----|--------|
| Контур | Ноя vs всё остальное | `NOY/`, `Другие/` |
| **Кабинет** | Профиль на Ное; один MCP-ключ | `dendriit/`, `Neyroagents/` |
| **Проект** | Папка работы внутри кабинета (или в Другие) | `anna/`, `легион/`, `bitrix-yurist/`, `Саприн и партнеры/` |
| **Агент** | Карточка на доске Нои (не обязательно = папка) | Анна, Легион |

**bitrix-yurist** в `Другие/`, потому что собран **не на платформе Ноя**, а отдельно на сервере. Ключ Нои ему не нужен.

## Ключи Cursor (на кабинет Нои)

| Кабинет | Секрет | Статус |
|---------|--------|--------|
| `NOY/dendriit/` | `NOYA_KEY_DENDRIIT` | MCP-папка: `noya-ai-mcp/` |
| `NOY/Neyroagents/` | `NOYA_KEY_NEYROAGENTS` | кабинет `4e2e1b84-87ee-4031-a8f1-2ea3cf9c6074`; не брать ключ dendriit |
| `Другие/*` | — | не Ноя |

MCP: `<cabinet>/.cursor/mcp.json` с `${env:NOYA_KEY_…}`.  
**Не** класть Ною в `~/.cursor/mcp.json`. Ключ не копировать между кабинетами.

## Как работать

1. Открыть папку **кабинета** (например `/Users/user/Projects/NOY/dendriit`).
2. `instruction_guide` → `whoami` → сверить с `.cursor/rules/noya-cabinets.mdc`.
3. Править файлы нужного **проекта** (`anna/` или `легион/`).

| Задача | Папка | Секрет |
|--------|-------|--------|
| Анна | `NOY/dendriit/` + `anna/` | `NOYA_KEY_DENDRIIT` |
| Легион | `NOY/dendriit/` + `легион/` | `NOYA_KEY_DENDRIIT` (тот же кабинет) |
| Воркфлоу / агент студии | `NOY/Neyroagents/` + `ДендрИИт/` | `NOYA_KEY_NEYROAGENTS` |
| Битрикс-Юрист | `Другие/bitrix-yurist/` | без ключа Нои |
| Саприн и партнеры | `Другие/Саприн и партнеры/` | без ключа Нои |

## Новый кабинет Нои

1. Папка в `NOY/<slug>/` (шаблон: `NOY/_cabinet-template/`).
2. Секрет `NOYA_KEY_<SLUG>` в Cursor Secrets.
3. `mcp.json` + `noya-cabinets.mdc`.
4. Внутри — папки проектов.
