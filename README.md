# Суды Воронежа → агент Нои

Как кормить ИИ-агента в Ное данными с сайтов ГАС «Правосудие», не ломая агента «Легион».

## Решение

Не подключать живые URL sudrf.ru в обход Нои. Сайты режут зарубежные и многие облачные IP (проверка с этого окружения: HTTP 200 и текст «запрос заблокирован по соображениям безопасности (G)»).

Рабочая схема из трёх слоёв:

1. **База знаний (сейчас)** — markdown из `knowledge/seed/` загружается в БЗ нового агента. Это контакты, районы, ссылки на `sud_delo`.
2. **Парсер с российского IP (обновление БЗ)** — `python -m parser.cli` снимает страницы судов и кладёт текст в `knowledge/live/`. Файлы снова кладутся в БЗ Нои.
3. **Живой поиск дел (позже)** — маленький HTTP-сервис на VPS в РФ. Действие агента в Ное бьёт в webhook: номер дела / ФИО → JSON. Без российского адреса это не заработает.

## Ноя

В этом окружении MCP Нои нет, кабинет ДендрИИт отсюда не дергается. Готовый бриф агента: `noe/agent-setup.md`. Создавать доску и агента — в чате, где уже есть MCP Нои, **не трогая** `Легион — продавец` (`b7bf93fd-41dc-4fb3-9c48-de6de9ea84f3`).

## Запуск парсера

```bash
python -m parser.cli --out knowledge/live
```

Код выхода `2` означает полную блокировку IP. Перенести запуск на машину в РФ и повторить.
