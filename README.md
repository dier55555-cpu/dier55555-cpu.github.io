Мультипроектный репозиторий с двумя контурами.

- **`noya/`** — платформа **Ноя**
  - `noya/_shared/` — методологии и инструкции **только для Нои**
  - `noya/projects/anna/` — проект Анны
- **`другие/`** — всё вне Нои (отдельно, чтобы инструкции Нои не применялись сюда)
