# dier55555-cpu.github.io

Мультипроектный репозиторий.

## Как устроены папки

- **`noya/`** — все проекты и общие материалы платформы **Ноя**
  - `noya/_shared/` — методологии, шаблоны промптов и прочее общее
  - `noya/projects/<имя>/` — конкретные проекты на Ное
- **Соседние папки в корне** — проекты на других платформах (каждая платформа/контур — своя папка)

Правила для агентов: `AGENTS.md` и `.cursor/rules/workspace-layout.mdc`.

Корневой `index.html` — публичная страница репозитория, не проект Нои.
