# Ноя (Noya)

Всё, что делается **на платформе Ноя**, живёт здесь.

## Папки

| Путь | Назначение |
|------|------------|
| `_shared/` | Общие инструкции Нои: методология промптов, шаблоны, соглашения. **Не для папки `другие/`** |
| `projects/anna/` | Проект Анны |
| `projects/<имя>/` | Другие проекты на Ное |

## Как добавлять проект

1. Создать `noya/projects/<slug>/`.
2. Прочитать `_shared/` перед реализацией.
3. Держать артефакты проекта внутри его папки.
4. Кросс-проектные знания Нои — в `_shared/`, не дублировать.
