# Ноя (Noya)

Всё, что делается **на платформе Ноя**, живёт здесь.

## Папки

| Путь | Назначение |
|------|------------|
| `_shared/` | Общие файлы для всех проектов Нои: методология промптов, шаблоны, соглашения |
| `projects/<имя>/` | Отдельный проект / бот / база знаний на Ное |

## Как добавлять проект

1. Создать `noya/projects/<slug>/`.
2. Прочитать `_shared/` перед реализацией.
3. Держать артефакты проекта внутри его папки.
4. Если появилось знание, полезное **всем** проектам Нои — положить в `_shared/`, не дублировать.
