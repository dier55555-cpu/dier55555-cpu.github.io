# Общие материалы платформы Ноя

Файлы в этой папке относятся ко **всем** проектам в `noya/projects/`.

Агент при любой задаче на Ное должен сначала просмотреть содержимое `_shared/` и опираться на него.

## Что сюда класть

- методология написания промптов
- шаблоны системных / пользовательских промптов
- соглашения по структуре knowledge base
- чеклисты выкладки на Ною
- другие кросс-проектные гайды

## Что сюда не класть

- код и данные конкретного бота/проекта → это в `noya/projects/<имя>/`
- материалы вне Нои → только `другие/<проект>/` (инструкции из этой папки туда не тащить)
