# Другие проекты (вне Нои)

Всё, что **не** на платформе Ноя.

Папка отделена от `noya/` специально: инструкции и методология из `noya/_shared/` сюда **не** применяются.

## Проекты

| Папка | Описание |
|-------|----------|
| `юристы/` | Проект с юристами |

Новый проект вне Нои → создать `другие/<имя>/`.
